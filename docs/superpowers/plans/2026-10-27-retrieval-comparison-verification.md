# 四策略检索对照与瓶颈定位

本轮落实既定步骤 7 的检索对照部分，新增可重放的四策略评测与证据丢失阶段归因。线上排序策略、工具、提示词、索引内容和文档切割均保持原样。完整上线门槛仍待验证。

## 实验口径

- 使用同一 `flowpay_docs_v1_qwen3_06b` ready 集合、机器与查询，真实只读 PostgreSQL、BM25 和 CUDA Cross-Encoder。
- 24 道已查看诊断题，来自 15 个场景族。它们用于分析现有问题，不能称为新的留出验收集。
- 每路召回 50、RRF 选 30、最终 K=6，混合排序沿用重排权重 0.75。四策略统一六片段上限。
- 查询向量回放之前同版本真实嵌入结果，未重新请求嵌入服务；新读库结果必须与冻结 RRF 候选的完整对象及顺序相同。模型对候选重新执行真实推理，分数重放的 Top-6 必须与协调器实际输出相同。
- 每题每策略单独预热一次，再测三轮，轮换策略顺序，并核对三轮结果顺序稳定。每策略共 72 个热态计时，质量样本仍为 24 题。
- 指定证据组和已知正例标签来自此前固定输入与补审标签。未判断片段保持未知；正式 nDCG 为 null。不同策略的已判断片段池不可比，因此新报告移除条件性 judged-pool nDCG。
- 差异区间以场景族为 bootstrap 单位，固定随机种子，重复 2,000 次；不会把热态重复执行算成新增独立样本。

## 相同 Top-6 预算的诊断结果

| 策略 | 平均指定证据组覆盖 | 指定正例 Recall | 检索方法热态 p95 |
| --- | ---: | ---: | ---: |
| Dense | 53.82% | 33.86% | 14.57 ms |
| BM25 | 52.08% | 34.00% | 13.14 ms |
| RRF | 59.72% | 40.18% | 24.85 ms |
| Hybrid | 64.58% | 44.73% | 649.87 ms |

覆盖和 Recall 是逐题平均。耗时排除查询嵌入生成、外部聊天模型与 HTTP 工具循环；Hybrid 包含生产协调器的阶段追踪，其余策略是直接算法/读库入口。因此这些数字描述本次检索方法测量范围，不能替代完整在线延迟或纯算力对比。模型准备约 21.50 秒，BM25 准备约 0.53 秒，均排除在热态统计外。

| 配对差异 | 平均差异 | 场景族 bootstrap 95% 区间 | 逐题退化数 |
| --- | ---: | ---: | ---: |
| Hybrid − Dense，证据组覆盖 | +10.76 个百分点 | −3.53 至 +29.17 | 2 |
| Hybrid − Dense，指定正例 Recall | +10.87 个百分点 | +1.25 至 +20.53 | 3 |
| Hybrid − RRF，证据组覆盖 | +4.86 个百分点 | 0 至 +10.14 | 0 |
| Hybrid − RRF，指定正例 Recall | +4.55 个百分点 | −1.05 至 +10.83 | 2 |

这些是已见小样本的探索性诊断。覆盖差异仍不足以证明稳定增益，也不支持默认启用。相对 Dense 的证据组覆盖退化集中在 `FP-BM-MD-0022` 和 `FP-BM-MD-0082`，已保留逐题结果。

## 证据丢失位置

对每个指定组依次检查：两路召回并集是否包含任一完整替代方案、RRF Top-30 是否仍包含、最终 Top-6 是否覆盖。多片段替代方案必须全部命中才算覆盖。

| 阶段 | 指定组数 |
| --- | ---: |
| 已覆盖 | 28 |
| 两路召回均未完整覆盖 | 2 |
| RRF Top-30 截断丢失 | 4 |
| 已进 Top-30，但最终 Top-6 未覆盖 | 14 |

总计 48 个指定组，未覆盖 20 个，其中 **70% 在最终选择阶段丢失**。这一计数按证据组统计，与上表逐题平均覆盖率采用不同权重。

下一轮优先比较最终片段选择策略，评估多证据问题的覆盖及上下文预算；其次检查 RRF 截断的 4 个组。改进必须在冻结诊断失败集之外另做场景族隔离确认，继续保留逐题退化记录。
